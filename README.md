# PAINTIT! 🎨
**Made by ALTINDAG ©**

A lightweight, fast, and modular screen annotation tool that allows you to draw, take notes, and create professional presentations freely on your screen. 

## 🚀 Features
* **Drag-and-Drop HUDs:** Transparent, stylish, closable and freely movable panels for tools, shapes, text, and media.
* * **Main Presentation Elements:** You can draw things, erase them, and freely use different pens or shapes. There is even more!
* **Live Lens (Magnifier):** A live magnifying glass tool for presentations that enlarges the screen area around your cursor by 2x.
* **Smart Select & Cut (Scissors):** Select any drawn area on your screen, cut it, and instantly turn it into a freely movable, resizable floating image object.
* **Advanced Text Boxes:** Spawn floating text boxes; edit font color, size, bold, and italic properties on the fly.
* **Rich Shape Tools:** Arrow, dashed line, rectangle, ellipse, and a solid censor marker.
* **Image Elements:** Instantly spawn images copied  from the web or your local machine directly onto your screen (Ctrl+V) or upload them directly. You can also adjust them easily. 

## ⌨️ Keyboard Shortcuts
Use the following shortcuts to speed up your workflow:
* **H** - Toggle Main HUD (Show/Hide)
* **P** - Pen Tool
* **E** - Eraser
* **T** - Text Tool
* **B** - Paint Bucket
* **S** - Select/Cut Tool
* **Z** - Live Lens
* **M** - Censor Marker
* **SHIFT + LEFT CLICK** - Draw as a perfectly straight line.
* **Ctrl + Z** - Undo
* **Ctrl + Y** - Redo
* **Ctrl + V** - Paste Image from Clipboard
* **ESC** - Close the application
